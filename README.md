# LabInsight AI

## Medical Laboratory Data Analysis and Disease Prediction

LabInsight AI is an AI-powered medical laboratory data analysis system designed to assist doctors and laboratory technicians in analyzing patient laboratory test data and identifying potential disease risks.

## Project Status

?? Currently Under Development

## Objectives

- Analyze patient laboratory test data.
- Provide centralized patient information and test history.
- Predict potential disease risks using machine learning.
- Provide separate dashboards for doctors and laboratory technicians.
- Identify important laboratory parameters influencing predictions.
- Generate useful reports from laboratory data.

## Key Features

- Patient search and laboratory test history
- Doctor dashboard
- Laboratory Technician dashboard
- Diabetes prediction
- Heart disease prediction
- Kidney disease prediction
- SHAP-based explainability
- Report generation
